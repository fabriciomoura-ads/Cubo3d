Como ler os movimentos

Cada letra é uma face, sempre olhando o cubo de frente. Sozinha, a letra significa girar aquela face no sentido horário como se você estivesse olhando direto para ela.

R
Direita (Right) — sobe
L
Esquerda (Left) — desce
U
Topo (Up) — vai para a esquerda
D
Base (Down) — vai para a direita
F
Frente (Front) — horário
B
Trás (Back) — topo vai p/ esquerda
X'
Apóstrofo: sentido contrário
X2
Meia volta (duas vezes)
y
Gira o cubo inteiro, como o U
